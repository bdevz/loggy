## Portable project context

Read `.ai/STANDARDS.md` and `.ai/PROJECT.md` at session start, then `.ai/DECISIONS.md`, `.ai/LESSONS.md`, and the relevant recent `.ai/handoffs/` entry. If installed, `harness context` assembles these with live Git state.

Before a meaningful handoff, update those files and save a checkpoint with `harness checkpoint`. If the command is unavailable, write a dated Markdown file in `.ai/handoffs/` with the goal, changes, reasons, validation results, remaining questions, and exact next action. Keep existing project-specific instructions and never store credentials in notes.
